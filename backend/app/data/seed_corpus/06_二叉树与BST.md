# 二叉树与二叉搜索树

## 二叉树基本概念
二叉树每个节点至多两个孩子,区分左右。满二叉树每层填满;完全二叉树只允许最后一层右侧缺失,可用数组紧凑存储(下标 i 的孩子为 2i+1、2i+2)。n 个节点的二叉树高度最小约 log2(n),最大 n(退化为链)。

## 四种遍历
前序(根左右)、中序(左根右)、后序(左右根)为深度优先,层序为广度优先(队列实现)。中序遍历二叉搜索树得到递增序列,这是 BST 验证与第 k 小元素问题的关键性质。已知前序+中序或后序+中序可唯一重建二叉树;仅前序+后序不能唯一确定。

```python
def inorder(root, out):
    if not root:
        return
    inorder(root.left, out)
    out.append(root.val)      # 访问根
    inorder(root.right, out)
```

## 二叉搜索树 BST
BST 性质:左子树所有节点 < 根 < 右子树所有节点。查找、插入、删除平均 O(log n),最坏(退化成链)O(n)。删除分三种情况:叶子直接删;单孩子用孩子顶替;双孩子用中序后继(右子树最小节点)替换值后删除后继。

## 平衡的意义
按有序序列依次插入 BST 会退化为链表。AVL 树通过旋转维持左右子树高度差不超过 1,红黑树以更宽松的约束换取更少旋转,二者将操作稳定在 O(log n)。

## 易错点
1. 验证 BST 只比较父子节点——必须用区间上下界(min, max)递归校验整棵子树。
2. 删除双孩子节点时直接删根而不是替换后删后继。
3. 混淆"完全二叉树"与"满二叉树"。
4. 递归遍历忘记空节点判断导致 None 解引用。
