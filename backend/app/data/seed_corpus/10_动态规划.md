# 动态规划

## 适用条件与解题框架
动态规划要求问题具备最优子结构(原问题最优解由子问题最优解构成)与重叠子问题(子问题被反复求解)。无后效性指当前状态确定后,未来决策不依赖到达该状态的路径。解题四步:定义状态 → 写状态转移方程 → 确定初始条件与边界 → 明确遍历顺序(保证转移所需状态已算出)。

## 入门:爬楼梯与打家劫舍
爬 n 阶楼梯每次 1 或 2 步:f(n)=f(n-1)+f(n-2),即斐波那契。打家劫舍不可偷相邻:dp[i]=max(dp[i-1], dp[i-2]+nums[i]),体现"选或不选"的决策型转移。

## 经典:0-1 背包
容量 C、n 件物品各有重量 w 与价值 v,每件至多取一次。dp[i][j] 表示前 i 件、容量 j 的最大价值:dp[i][j]=max(dp[i-1][j], dp[i-1][j-w[i]]+v[i])。滚动数组压缩到一维后,01 背包容量必须倒序遍历(防止同一物品重复使用);完全背包则正序遍历。

```python
def knapsack01(C, items):
    dp = [0] * (C + 1)
    for w, v in items:
        for j in range(C, w - 1, -1):   # 倒序!
            dp[j] = max(dp[j], dp[j - w] + v)
    return dp[C]
```

## 序列型:LIS 与 LCS
最长递增子序列 LIS:dp[i] 表示以 i 结尾的最长长度,O(n^2);贪心 + 二分维护 tails 数组可 O(n log n)。最长公共子序列 LCS:二维 dp,相等时左上角 +1,否则取上、左最大值。

## DP 与记忆化、贪心的关系
记忆化搜索是自顶向下的 DP,递推是自底向上;二者复杂度同阶,递推常数更小。贪心是 DP 的特例:当局部最优可证全局最优时才可用,如找零问题在特定币值系统下贪心正确,任意币值则需 DP。

## 易错点
1. 01 背包一维写成正序,物品被重复选取。
2. 状态定义含糊,如 LIS 的 dp[i] 忘记"必须以 i 结尾"导致答案取错位置。
3. 遍历顺序与转移依赖冲突,用到还没算的状态。
4. 初始边界遗漏,如背包 dp[0] 与空串行列未初始化。
