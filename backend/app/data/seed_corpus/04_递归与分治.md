# 递归与分治

## 递归三要素
递归函数自己调用自己,必须具备:终止条件(base case)、向终止收敛的子问题、子问题与原问题同构。缺少终止条件或参数不收敛会栈溢出。

```python
def factorial(n: int) -> int:
    if n <= 1:          # 终止条件
        return 1
    return n * factorial(n - 1)   # 规模收敛
```

## 递归的执行模型
每次调用在调用栈上压入一帧,保存参数与返回地址;到达 base case 后逐层回溯。递归深度即栈空间消耗,Python 默认递归深度约 1000,深递归需改迭代或显式栈。

## 分治法
分治三步:分解(Divide)子问题、解决(Conquer)递归求解、合并(Combine)子解。归并排序、快速排序、二分查找、大整数乘法均是分治。复杂度用递推式 + 主定理:T(n)=aT(n/b)+f(n),比较 f(n) 与 n^(log_b a) 决定结果。

## 记忆化:消除重复子问题
朴素递归求斐波那契 fib(n)=fib(n-1)+fib(n-2) 重复计算量指数级 O(2^n);加缓存(记忆化)后每个子问题只算一次,降为 O(n)。这是通往动态规划的桥梁。

## 易错点
1. 终止条件不全,如 fib 只写 n==0 漏掉 n==1。
2. 递归内修改可变默认参数(def f(x, memo={}))导致跨调用串扰。
3. 把"递归就是慢"当结论——重复子问题才是慢的根源,树形递归配记忆化可以很快。
4. 回溯时忘记撤销现场(undo choice),导致状态污染。
