# 栈与队列

## 栈:后进先出 LIFO
栈只允许在栈顶进行压入(push)与弹出(pop),两种操作均 O(1)。典型应用:函数调用栈、括号匹配、表达式求值(中缀转后缀)、浏览器后退、深度优先搜索的迭代实现、单调栈求"下一个更大元素"。

```python
def is_valid_brackets(s: str) -> bool:
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()
    return not stack  # 栈空才完全匹配
```

## 队列:先进先出 FIFO
队列在队尾入队、队头出队,均 O(1)。顺序存储时为避免"假溢出"采用循环队列:用取模运算让下标回绕,判满常牺牲一个单元(rear+1) % n == front,或额外维护 size。应用:广度优先搜索、任务调度、消息队列。

## 双端队列与优先队列
双端队列(deque)两端均可进出,滑动窗口最大值用单调双端队列 O(n) 解决。优先队列按优先级出队,底层通常用堆实现,见第7章。

## 栈实现队列、队列实现栈
两个栈可模拟队列:入队压 in 栈,出队时若 out 栈空则把 in 栈全部倒入 out 栈,均摊 O(1)。这是"均摊分析"的经典例子。

## 易错点
1. 循环队列判空判满条件混淆:front == rear 为空,(rear+1) % n == front 为满(牺牲一格方案)。
2. 用 Python list 当队列从头部 pop(0) 是 O(n),应使用 collections.deque。
3. 括号匹配漏判"扫描结束栈非空"的情形,如输入 "(((" 应返回 False。
4. 单调栈方向搞反——求下一个更大元素应维护递减栈。
