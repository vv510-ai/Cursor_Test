# 数组与链表

## 数组(顺序表)
数组在内存中连续存放,支持 O(1) 随机访问:地址 = 基址 + 下标 × 元素大小。插入或删除中间元素需要搬移后续元素,平均 O(n)。动态数组(如 Python list、C++ vector)容量不足时按约 2 倍扩容并整体搬迁,单次扩容 O(n),但均摊到每次追加仍是 O(1)。

## 单链表
链表节点由数据域与指针域构成,逻辑相邻而物理分散。已知前驱节点时插入与删除仅需改指针,O(1);但按下标访问必须从头逐个走,O(n)。

```python
class ListNode:
    def __init__(self, val=0, nxt=None):
        self.val = val
        self.next = nxt

def insert_after(node, val):
    """在 node 之后插入新节点:先接后断,顺序不能反"""
    new = ListNode(val)
    new.next = node.next
    node.next = new
```

## 双向链表与循环链表
双向链表每个节点多一个 prev 指针,可 O(1) 删除自身(无需找前驱),LRU 缓存即用哈希表 + 双向链表实现。循环链表尾节点指回头节点,适合轮转调度场景。

## 数组 vs 链表选型
读多写少、需要随机访问选数组;频繁在中间插删、长度变化剧烈选链表。数组缓存局部性好,实际常数远小于链表。

## 易错点
1. 链表插入先断后接导致后续节点丢失——务必先 new.next = node.next 再 node.next = new。
2. 删除节点忘记处理头节点的特殊情况——引入虚拟头节点(dummy)可统一逻辑。
3. 快慢指针找中点时,循环条件 while fast and fast.next 写错导致空指针。
4. 误以为链表节省内存——每个节点的指针域本身也是开销。
