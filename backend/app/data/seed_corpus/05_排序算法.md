# 排序算法

## 基础排序 O(n^2)
冒泡排序相邻比较交换,稳定;选择排序每轮选最小放前面,不稳定,交换次数最少;插入排序把当前元素插入前面有序区,稳定,对基本有序数据接近 O(n)。三者空间均 O(1)。

## 归并排序 O(n log n)
分治:递归排左右两半,再线性合并两个有序数组。稳定;需 O(n) 辅助空间;最坏情况仍 O(n log n),是外部排序与链表排序的首选。

```python
def merge(a, b):
    i = j = 0
    out = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:        # 取等号保证稳定性
            out.append(a[i]); i += 1
        else:
            out.append(b[j]); j += 1
    out.extend(a[i:]); out.extend(b[j:])
    return out
```

## 快速排序 平均 O(n log n)
选基准 pivot 分区:小于基准的放左,大于的放右,递归两侧。平均 O(n log n)、原地、不稳定;最坏 O(n^2)(如对有序数组取首元素为基准)。工程上用随机基准或三数取中规避,小区间切换插入排序。

## 堆排序 O(n log n)
建大顶堆 O(n),每次取堆顶与末尾交换再下沉,原地、不稳定,常数比快排大,但最坏仍 O(n log n)。

## 计数/桶/基数排序
非比较排序可突破 O(n log n) 下界:计数排序 O(n+k) 适合小范围整数;基数排序按位分配收集,稳定。比较排序的理论下界为 O(n log n),由决策树高度证明。

## 稳定性与选型
稳定性指相等元素排序后保持原相对次序。多关键字排序需要稳定算法;Python 内置 sorted 是 Timsort(归并+插入混合,稳定)。

## 易错点
1. 快排递归未排除基准自身导致死循环;分区边界 i、j 交叉条件写错。
2. 归并合并时用 < 而非 <= 破坏稳定性。
3. 认为堆排序稳定——堆的下沉会打乱相等元素次序。
4. 把"快排一定比归并快"当真理——最坏退化与缓存行为都需考虑。
