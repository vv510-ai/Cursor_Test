# 堆与优先队列

## 堆的定义与存储
堆是用数组表示的完全二叉树。大顶堆任意父节点 ≥ 孩子;小顶堆相反。下标 i 的父节点 (i-1)//2,孩子 2i+1、2i+2。堆只保证父子偏序,兄弟之间无大小关系,因此堆不是有序数组。

## 核心操作
上浮 sift-up:新元素插入末尾后与父比较交换,O(log n)。下沉 sift-down:堆顶被替换后与较大(或较小)孩子交换,O(log n)。自底向上建堆从最后一个非叶节点逐个下沉,总代价 O(n),优于逐个插入的 O(n log n)。

```python
import heapq           # Python 内置小顶堆
h = []
heapq.heappush(h, 5)
heapq.heappush(h, 1)
top = heapq.heappop(h)  # 1,弹出最小
```

## 典型应用
优先队列(任务调度、Dijkstra 取最近节点)、Top-K 问题(求最大的 K 个数维护大小为 K 的小顶堆,O(n log K))、多路归并、中位数对顶堆(大顶堆放小半边、小顶堆放大半边)。

## 易错点
1. Top-K 求"最大 K 个"误用大顶堆全量弹 K 次——海量数据应维护 K 容量小顶堆。
2. 认为堆中序遍历有序——堆不具备 BST 性质。
3. 建堆复杂度误记为 O(n log n)——自底向上是 O(n)。
4. Python heapq 是小顶堆,求大顶堆需取负数入堆。
