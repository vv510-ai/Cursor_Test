## 每个人开发前先做

进入自己的目录：

```powershell
cd C:\Users\26054\Desktop\sparklearn-profile-path-eval
```

查看当前状态：

```powershell
git status
```

如果看到很多红色文件，先不要乱改，问负责合并的人。

## 启动后端

第一次进入新的 worktree 后，需要自己建 Python 环境并装依赖：

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

后端地址：

```text
http://127.0.0.1:8000/docs
```

## 启动前端

第一次进入新的 worktree 后，需要装依赖：

```powershell
cd frontend
npm install
npm run dev
```

前端地址：

```text
http://127.0.0.1:3000
```

## 中间产物在哪里

每次后端跑资源生成，都会自动写入：

```text
backend/runs/{session_id}/
```

重点看：

```text
request.json
events.jsonl
profile.output.json
planner.output.json
path.output.json
resources/
agent_end/
eval.output.json
final_state.json
summary.json
```

这些文件不要提交到 git，它们已经被 `.gitignore` 忽略。

## 提交自己的修改

只提交自己负责的改动：

```powershell
git status
git add 你改过的文件
git commit -m "feat: 简短说明你做了什么"
```

不要使用：

```powershell
git add .
```

除非你非常确认没有混入临时文件。

## 合并回主目录

由一个人统一合并，建议在主目录执行：

